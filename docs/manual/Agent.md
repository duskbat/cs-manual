在我们的日常工作中，理所当然想到的是替代我们自己的工作。我们组内首先想到的是 AI CR。

## Harness

| 代际   | 范式                | 核心问题                | 形象对比                               |
| ------ | ------------------- | ----------------------- | -------------------------------------- |
| 第一代 | Prompt Engineering  | 怎么把话说清楚          | 对马喊话的技巧                         |
